# 商品尺码选购指南

把商家确认的尺码表、量法和选码条件整理成顾客可核对的选码范围，减少凭身高体重猜尺码。只处理一个商品的已确认信息：不承诺合身，不修改 SKU 或库存。

**你提供：**尺码档位与尺寸、单位、适用部位、商家测量方法和允许的选码规则（可附顾客实测尺寸）。

**你得到：**统一单位的尺码表、可执行的测量步骤、逐组按规则筛选的候选尺码范围，以及需要补充确认的字段。缺单位、量法或关键尺寸会停止推荐；只有身高体重不会推造适配结论。

**立即使用：**将输入保存为 JSON 后运行 `node scripts/guide.mjs input.json`。

## 能力、输入与结果

**输入：**尺码档位及对应尺寸、单位、适用部位、商家测量方法和允许的选码规则；可附最多 5 组顾客实测尺寸。

**结果：**统一单位的完整尺码表、可执行的测量步骤、每组顾客按给定规则筛出的尺码范围，以及需要商家或顾客补充确认的字段。缺少单位、量法或关键尺寸，或字段与量法、适用部位不匹配时，会停止推荐；只有身高体重不会推造适配结论。

## 怎么用

提供尺码表和商家确认的测量方法、选码规则，运行 `node scripts/guide.mjs input.json`；脚本逐组比对尺寸并列出符合范围或待确认项，不用身高体重推测尺码。

## 适用范围

最多 20 档尺码与 5 组顾客测量。分组输入时，顶层范围汇总测量完整的顾客组候选尺码，明细逐组展示结果；缺少测量会列待补字段，不误报没有尺码合适。仅整理商家量法和明确条件：不承诺合身，不修改 SKU 或库存，不以身高体重推造适配。

## 可复制示例

- [成功输入与预期交付](fixtures/success.json)：顾客胸围 88 cm、至少留 6 cm；尺码表直接提供成衣胸围 92/96 cm，仅 L（96 cm）符合。测量说明提醒复核时将平量胸宽乘 2，脚本不对尺码表数值重复换算。
- [失败输入与预期交付](fixtures/failure.json)：仅有 M/L、缺尺寸和量法时请求补料，不依据体重选 M。

运行示例：`node scripts/guide.mjs fixtures/success.json`。运行独立检查：`node scripts/self-test.mjs`。
